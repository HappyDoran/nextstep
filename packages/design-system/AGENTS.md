# 지역 작업 규칙

React 표현 컴포넌트와 tokens.css를 소유한다. API·인증·지원 상태 판정은 넣지 않는다. 공통 컴포넌트의 기본·비활성·오류 등 존재하는 상태를 Storybook과 실제 웹에서 확인한다. 한국어 문구·키보드 포커스·대비를 고려한다. 브랜드 색상 선택은 README.md를 따른다. 화면·타입·테마 전체 스타일이 확정된 것으로 보고하지 않는다.

토큰·타입·아이콘 작업은 README.md를 읽는다. Lucide React를 직접 사용하고 별도 아이콘 레지스트리나 래퍼를 만들지 않는다.

UI 스타일은 공유 preset의 Tailwind 유틸리티로 작성한다. 타입·아이콘 전용 일반 CSS 클래스나 styled-components를 만들지 않는다. 변수·테마·폰트의 CSS와 유틸리티 소비를 구분한다.
