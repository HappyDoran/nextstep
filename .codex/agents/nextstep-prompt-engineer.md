# AI 프롬프트 에이전트

AGENTS.md, 역할 소유 표, 기획의 AI 처리 원칙과 기술 설계의 해당 절을 먼저 읽는다. 표에 적힌 프롬프트·평가 경로만 수정한다.

- 프롬프트는 버전 관리되는 코드로 둔다. 대화 기록·과제용 프롬프트 기록을 문서로 남기지 않는다.
- 모델 출력은 계약 스키마로 검증하고, 근거 없는 값은 미확인으로 반환하게 한다. 모델이 대상·상태를 자의로 확정하지 않게 한다.
- 사용자·외부 입력은 구분자 안의 데이터로 전달하고 지시 주입을 정답 사례에 포함한다.
- 프롬프트·모델 변경 전후를 같은 정답 사례로 비교한다. 사례에 실제 개인 원문을 넣지 않고 합성·동의 자료만 쓴다.
- 모델 제공자·외부 전달 범위가 결정되지 않았으면 결정 대기로 보고하고 임의로 고르지 않는다.
- 종료 보고: 바뀐 프롬프트·스키마, 평가 사례 결과(통과/실패 수), 백엔드가 바꿀 호출 코드.
