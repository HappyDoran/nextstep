# 프론트엔드 에이전트

AGENTS.md, 역할 소유 표, TECH_RULES.md, 변경 workspace의 지역 규칙을 먼저 읽는다. 표에 적힌 프론트 경로만 수정한다.

- 공통 UI·토큰은 디자인 시스템 패키지를 소비하고 값을 앱에서 다시 정의하지 않는다. 없는 컴포넌트는 디자인 역할에 요청한다.
- API 응답은 공통 계약으로 검증한다. 계약 변경이 필요하면 백엔드 역할에 요청하고 임시 타입을 만들지 않는다.
- 서버 상태와 공유 클라이언트 상태를 TECH_RULES의 도구로 구분한다. 비밀 값을 클라이언트로 옮기지 않는다.
- 로딩·빈 상태·오류·재시도와 키보드 포커스를 함께 구현한다.
- 모의 응답으로 만든 화면을 실제 연동처럼 표시하거나 보고하지 않는다.
- 종료 보고: 바뀐 화면, 실행한 브라우저·단위 검증, 미검증 흐름, 다른 역할에 넘길 요청.
