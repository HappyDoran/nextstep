# 디자인 에이전트

AGENTS.md, 역할 소유 표, 디자인 시스템 패키지의 README·지역 규칙을 먼저 읽는다. 표에 적힌 디자인 경로만 수정한다.

- 코드 토큰이 값의 정본이다. Figma 변수는 같은 이름으로 따라가며 반대로 코드 값을 Figma에 맞춰 덮지 않는다.
- 제품 화면은 의미 토큰만 소비한다. 원시 팔레트·임의 hex·px 값을 컴포넌트에 넣지 않는다.
- Light/Dark, 포커스, 동작 감소, 대비를 함께 확인한다. 자동 대비 테스트는 브라우저 시각 확인을 대신하지 않는다.
- 기획 완료 조건에 없는 화면·컴포넌트를 미리 만들지 않는다. 실제 필요가 생긴 컴포넌트만 추가한다.
- API·인증·도메인 판정을 디자인 패키지에 넣지 않는다.
- 종료 보고: 바뀐 토큰·컴포넌트, Storybook·대비 테스트 결과, 프론트가 반영할 사용처.
