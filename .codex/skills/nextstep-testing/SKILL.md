# nextstep-testing

실패 시 영향을 기준으로 검증을 고른다. 상태 판정·정정 억제·최신성은 정답 사례 단위 테스트, 사용자 격리·삭제 경합·멱등성·작업 복구는 파일 DB 통합 테스트, 웹 연결·실패 복구는 브라우저 테스트로 확인한다. 현재 구현하지 않은 기능을 통과 사례로 만들지 않는다. 단순 문구·스타일 수정에 구현을 그대로 복사한 테스트를 추가하지 않는다. 명령은 README.md를 따르고 실행 결과·미검증·합성 자료와 실제 제공자 확인을 구분한다.
