# nextstep-doc-policy

AGENTS.md의 문서 맵에서 기존 소유자를 찾는다. 같은 사실을 새 문서로 복사하지 않는다. 새 문서는 현재 구현·반복 작업에 필요한 사실을 독립적으로 소유할 때만 만들고 문서 맵에 연결한다. 기획서의 요구와 현재 코드가 다르면 요구를 낮추지 말고 README.md의 현재 구현 상태에 차이를 명시한다. 미구현 기능의 사용법·빈 placeholder·과제용 프롬프트/활용 보고서를 만들지 않는다. 루트 규범 문서와 docs 아래 문서에는 title·kind·last_verified frontmatter를 두고 내용을 확인한 날 last_verified를 갱신한다. 한국어와 상대 링크를 확인하고 구조 검사를 실행한다.
