# nextstep-spec-discovery

요구·단계 범위·완료 조건은 docs/spec/서비스기획서_v0.2.md, 데이터·작업·보호 설계는 docs/spec/기술설계_부록.md가 소유한다. 사용자만 정할 수 있는 결정은 대신 정하지 않는다.

1. 문제와 사용자를 근거와 함께 쓴다. 근거가 없으면 가설로 표시한다.
2. 1차 범위는 검증 가능한 가장 작은 단위로 둔다. 하고 싶은 기능은 지우지 않고 2차 확장·후속 후보 절로 옮기며 도입 조건을 적는다.
3. 완료 조건은 다른 작업자가 검증 명령이나 화면 확인으로 판정할 수 있게 쓴다.
4. 인증 수단·AI 처리 제공자·배포 환경·가격처럼 사용자가 정할 것은 docs/spec/gap-analysis.md 미결 결정 표에 선택지와 막는 단계를 적고 질문한다.
5. 범위가 바뀌면 gap-analysis 백로그 단계와 기술 설계 부록의 영향 절을 함께 고친다. 요구를 조용히 줄이지 않는다.
