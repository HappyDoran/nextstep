# 기획서 버전 기록

[서비스 기획서](../서비스기획서.md)의 모든 상태를 버전별로 보관한다. 원본은 현재 기획서이고, 가장 높은 번호의 기록본은 현재 기획서와 본문이 같아야 한다(구조 검사가 확인). 기록본은 고치지 않는다.

번호 규칙: 둘째 자리는 기획 구조가 바뀐 판(0.1: 1차/2차 구분, 0.2: 1·2차 통합·홈서버), 셋째 자리는 그 안의 수정 순서다. 기획서를 고치면 ① 현재 기획서 머리말의 버전을 올리고 ② 같은 본문을 `서비스기획서_<버전>.md`로 이 폴더에 복사하고 ③ 아래 표에 한 줄 추가한다. ①·②가 어긋나면 커밋이 막힌다.
