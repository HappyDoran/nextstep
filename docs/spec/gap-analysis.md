# 요구사항 대비 현재 상태와 백로그

요구와 1차 완료 조건 번호는 [서비스 기획서](서비스기획서_v0.2.md), 데이터·작업·보호 설계는 [기술 설계 부록](기술설계_부록.md)이 소유한다. 이 문서는 1차 구현 순서(P1)와 현재 상태, 착수를 막는 결정만 적는다. 항목을 끝내면 상태를 바꾸고, 확정된 결정은 TECH_RULES.md나 소유 설계 문서로 옮긴 뒤 여기서 지운다.

## 판정 요약 (2026-11-07)

- 완료: 로컬 실행 기반(모노레포·웹·API·SQLite·Electron 기본 창·공통 계약·디자인 기초). 구현 세부는 [README.md 현재 구현 범위](../../README.md#현재-구현-범위)가 소유한다.
- 결정(2026-11-07, 사용자): 수집을 서비스 모드와 개인 모드로 나누고 관리 토글로 바꾼다. 서비스 모드는 원티드·자소설닷컴을 사용자가 넣은 링크로만 판정하고, 개인 모드는 세 출처를 공개 페이지로 자동 수집한다. 메일 알림 경로는 이력서 대조 근거가 없어 채택하지 않았다. 근거는 기술 설계 부록 D절.
- 완료: P1-01(아래 검증 기록), P1-02, P1-03. 진행 중: P1-04. P1-05~07은 미착수다.
- 결정(2026-11-07, 사용자): AI 처리 제공자는 OpenAI API(TECH_RULES.md).
- 결정(2026-11-07, 사용자): 초대 인증은 초대 코드+이메일·비밀번호(TECH_RULES.md 신뢰 경계). 추천 판정 초기 규칙은 기술 설계 부록 D절대로 확정. 로컬 기반 구축은 비공개 MVP 완료가 아니며, 문서만 작성한 작업도 P1-01 완료가 아니다.
- 실제 연동과 저장을 검증하기 전에는 화면 완료를 서비스 완료로 보고하지 않는다. 일정은 출처·인증 검증 후 산정하며 사람/기간을 임의로 확정하지 않는다.
- 자동 테스트 범위: README.md 검증 절 기준.
