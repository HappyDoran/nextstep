# 요구사항 대비 현재 상태와 백로그

요구와 1차 완료 조건 번호는 [서비스 기획서](서비스기획서_v0.2.md), 데이터·작업·보호 설계는 [기술 설계 부록](기술설계_부록.md)이 소유한다. 이 문서는 1차 구현 순서(P1)와 현재 상태, 착수를 막는 결정만 적는다. 항목을 끝내면 상태를 바꾸고, 확정된 결정은 TECH_RULES.md나 소유 설계 문서로 옮긴 뒤 여기서 지운다.

## 판정 요약 (2026-11-07)

- 완료: 로컬 실행 기반(모노레포·웹·API·SQLite·Electron 기본 창·공통 계약·디자인 기초). 구현 세부는 [README.md 현재 구현 범위](../../README.md#현재-구현-범위)가 소유한다.
- 결정(2026-11-07, 사용자): 수집을 서비스 모드와 개인 모드로 나누고 관리 토글로 바꾼다. 서비스 모드는 원티드·자소설닷컴을 사용자가 넣은 링크로만 판정하고, 개인 모드는 세 출처를 공개 페이지로 자동 수집한다. 메일 알림 경로는 이력서 대조 근거가 없어 채택하지 않았다. 근거는 기술 설계 부록 D절.
- 진행 중: P1-01. 아래 P1-01 검증 기록 참고. P1-02~07은 미착수다. 로컬 기반 구축은 비공개 MVP 완료가 아니며, 문서만 작성한 작업도 P1-01 완료가 아니다.
- 실제 연동과 저장을 검증하기 전에는 화면 완료를 서비스 완료로 보고하지 않는다. 일정은 출처·인증 검증 후 산정하며 사람/기간을 임의로 확정하지 않는다.
- 자동 테스트 범위: README.md 검증 절 기준.

## 백로그 (우선순위 순)

요구사항 열의 `완료 N`은 기획서 8절 "1차 완료 조건" 번호다. 선행 단계가 끝나지 않으면 착수하지 않는다.

|---|---|---|---|---|

| P1-01 | 원티드·잡코리아·자소설닷컴 수집, 동의된 네이버 시험 계정의 읽기 전용 조회, 텍스트 PDF/MD 추출의 작은 기술 검증과 1차 네 직무 정답 사례. 선행: 동의된 시험 계정·공개 자료 | 완료 2·3의 선행, 기획서 9절 | 실제 추출·읽기 전용 조회 및 실패 구분. 구현 불가 출처·기업 정보 미확인 구분 | 진행 중 (잡코리아·네이버·PDF/MD 검증, 프론트엔드·앱 개발 정답 사례, 수집 모드 토글 완료. 개인 모드 원티드·자소설닷컴 공개 페이지 추출 검증·디자인·기획 정답 사례 남음) |

### P1-01 검증 기록 (2026-11-07)

| 항목 | 결과 | 근거 |
|---|---|---|
| 잡코리아 | 네 직무 검색 목록 4회·상세 12건 실제 조회. 제목·회사·마감(상시채용 구분)·경력·접수 방식·홈페이지 지원 URL·명시된 기업 유형/직원 수 추출. 이미지 원문 1건은 본문 실패로 구분. 검색어 목록에 다른 직무가 섞임 | `verify:jobkorea`, 개인회원 약관 제18조에 자동화 금지 조항 없음, robots.txt 공고 경로 허용 |
| 원티드 | 개인 모드 공개 페이지 추출은 미검증. 서비스 모드 대체 경로 후보였던 사용자 네이버 메일의 원티드 알림을 확인: 표본 80통 중 본문에 공고 링크가 직접 있는 메일 0통, 추적 링크 리다이렉트 10건 중 3건에서 공고 ID 확인(공고 페이지는 요청하지 않음). 마감·본문은 메일 내용 또는 사용자 브라우저 열람으로 확보해야 함 | 약관 제19조 7항(2026-08-06 시행). OpenAPI 개인 발급 불가 회신(2026-09-28, 원티드 OpenAPI 담당). `verify:naver` |
| 자소설닷컴 | 사이트 자동 수집 안 함. 사용자 메일함 최근 90일에 자소설닷컴 발신 메일 0통이라 메일 경로도 아직 없음 | 이용약관 금지행위 9호(자동화된 수단으로 정보 수집). 공식 API 미발견 |
| 네이버 IMAP | 실제 계정 읽기 전용 조회 성공. 편지함별 UIDVALIDITY·UID·최근 90일 건수, 재조회 시 읽음 플래그 불변, 증분 위치 이후 신규 0건, 잘못된 비밀번호는 `auth_failed`로 구분. 받은편지함 UIDVALIDITY 0, 존재 건수가 정확히 1000건이라 노출 상한 여부 확인 필요 | `verify:naver`. 별도 시험 계정이 아니라 사용자가 지정한 본인 계정으로 실행했고(사용자 결정 2026-11-07) 제목·주소·본문은 출력·저장하지 않음 |
| 이력서 추출 | 텍스트 PDF 한글 추출, 암호화·스캔·손상 PDF·형식·20MB 초과 구분, MD UTF-8 정규화 | `pnpm test`의 합성 픽스처 테스트 |
| 네 직무 정답 사례 | 프론트엔드 16건·앱 개발 15건 합성 사례(사용자의 실제 탐색 조건 React·Next.js·React Native·iOS·Swift, 서울/원격 기준, 주입 3건 포함)와 구조 검사. 모델 미결정으로 판정 정확도는 미측정. 디자인·기획 사례 미작성 | `apps/server/tests/prompts/recommendation-cases.json`, `pnpm test` |

## 미결 결정

기능 범위를 늘리기 위한 질문이 아니라 실제 연결·운영 설정이다. 구독 가격·환불·Windows 세부 배포·Gmail 공개 제공 준비는 2차 작업의 선행 조건이며 이 표에 두지 않는다.

| 결정 | 선택지 | 막는 단계 | 결정자 |
|---|---|---|---|
| 초대 인증 수단 | 미정. 초대 계정 인증·세션 만료·로그아웃을 충족해야 함 | P1-02 | 사용자 |
| AI 처리 제공자 | 미정. 외부 처리 범위를 사용자에게 안내해야 함 | P1-04·P1-05 | 사용자 |
| 별도 서버 배포 환경·운영 DB | 미정. 현재는 로컬 SQLite | P1-06 | 사용자 |
| macOS 최소 환경 | 미정 | P1-03 배포 검증 | 사용자 |
