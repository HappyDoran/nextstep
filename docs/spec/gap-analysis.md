# 요구사항 대비 현재 상태와 백로그

요구와 1차 완료 조건 번호는 [서비스 기획서](서비스기획서_v0.2.md), 데이터·작업·보호 설계는 [기술 설계 부록](기술설계_부록.md)이 소유한다. 이 문서는 1차 구현 순서(P1)와 현재 상태, 착수를 막는 결정만 적는다. 항목을 끝내면 상태를 바꾸고, 확정된 결정은 TECH_RULES.md나 소유 설계 문서로 옮긴 뒤 여기서 지운다.

## 판정 요약 (2026-11-07)

- 완료: 로컬 실행 기반(모노레포·웹·API·SQLite·Electron 기본 창·공통 계약·디자인 기초). 구현 세부는 [README.md 현재 구현 범위](../../README.md#현재-구현-범위)가 소유한다.
- 미착수: P1-01~07 전부. 로컬 기반 구축은 P1-01~07이나 비공개 MVP 완료가 아니며, 문서만 작성한 작업도 P1-01 완료가 아니다.
- 실제 연동과 저장을 검증하기 전에는 화면 완료를 서비스 완료로 보고하지 않는다. 일정은 출처·인증 검증 후 산정하며 사람/기간을 임의로 확정하지 않는다.
- 자동 테스트 범위: README.md 검증 절 기준.

## 백로그 (우선순위 순)

요구사항 열의 `완료 N`은 기획서 8절 "1차 완료 조건" 번호다. 선행 단계가 끝나지 않으면 착수하지 않는다.

| 단계 | 내용 | 요구사항 | 완료 조건 | 상태 |
|---|---|---|---|---|
| 기반 | pnpm/Turborepo·웹·API·SQLite DB 버전 관리·Electron 기본 창·공통 계약·디자인 기초 | 기획서 3·6절의 실행 기반 | README.md 검증 절의 `pnpm check`·`pnpm test:e2e`·`pnpm test:desktop` 통과 | 완료 (README.md 검증 절) |
| P1-01 | 원티드·잡코리아·자소설닷컴 수집, 동의된 네이버 시험 계정의 읽기 전용 조회, 텍스트 PDF/MD 추출의 작은 기술 검증과 1차 네 직무 정답 사례. 선행: 동의된 시험 계정·공개 자료 | 완료 2·3의 선행, 기획서 9절 | 실제 추출·읽기 전용 조회 및 실패 구분. 구현 불가 출처·기업 정보 미확인 구분 | 대기 (다음 착수) |
| P1-02 | 사용자·ID·DB 스키마·세션·삭제 경계. 선행: 최소 도메인·시험 환경 | 완료 1·8, 기획서 8절 보호 | 서로 다른 두 계정의 데이터 접근 차단·지속 저장·삭제 | 대기 |
| P1-03 | Electron 기본 화면·수동 지원·상태·설정. 선행: P1-02 | 완료 1, 기획서 4절 | 재실행 후 유지·외부 이동과 접수 구분·오류 표시 | 대기 |
| P1-04 | 이력서·필터·세 출처 수집·프론트엔드/앱 개발/디자인/기획 추천. 선행: P1-01~03 | 완료 2·8 | 세 출처·네 직무 범위의 실제 공고 추천·근거·기준 시각·실패 시 기존 문서 유지 | 대기 |
| P1-05 | 네이버 증분·대상 연결·판정·정정·확인 목록. 선행: P1-01~03, 이벤트·작업 기록 | 완료 3·4·5·7 | 실제 메일 접수/진행/결과·모호·재조회·재연결·정정 재처리 | 대기 |
| P1-06 | 서버 하루 한 번 예약·테스트 권한·자동 ON/OFF. 선행: P1-04~05 | 완료 6 | 앱 완전 종료 중 처리, 다음 실행 결과 표시·중복 방지 | 대기 |
| P1-07 | 오류·삭제·복구·비공개 사용자 검증. 선행: P1-02~06 | 완료 7·8·9 | 데이터 격리·삭제 경합·실패 복구·추천 유용성·정정 부담 확인 | 대기 |

## 미결 결정

기능 범위를 늘리기 위한 질문이 아니라 실제 연결·운영 설정이다. 구독 가격·환불·Windows 세부 배포·Gmail 공개 제공 준비는 2차 작업의 선행 조건이며 이 표에 두지 않는다.

| 결정 | 선택지 | 막는 단계 | 결정자 |
|---|---|---|---|
| 세 출처의 수집 제약 대응 | P1-01 검증 결과에 따라 출처별 방식·구현 불가 처리 | P1-04 | 사용자 |
| 초대 인증 수단 | 미정. 초대 계정 인증·세션 만료·로그아웃을 충족해야 함 | P1-02 | 사용자 |
| AI 처리 제공자 | 미정. 외부 처리 범위를 사용자에게 안내해야 함 | P1-04·P1-05 | 사용자 |
| 별도 서버 배포 환경·운영 DB | 미정. 현재는 로컬 SQLite | P1-06 | 사용자 |
| macOS 최소 환경 | 미정 | P1-03 배포 검증 | 사용자 |
